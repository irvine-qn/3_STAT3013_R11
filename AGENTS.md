## Project in one paragraph

Course project for STAT3013 (Statistical Analysis), group 03, class R11. We compare statistical and machine-learning models for **flood extent forecasting** under one fair protocol, and report results **by condition** (horizon, flood phase, flood magnitude, training-set size, region). Primary data: MODIS flood maps of the Vietnamese Mekong Delta (Vu et al. 2022, Mendeley DOI 10.17632/kpftzmsyyz.2). We will extend to other Vietnamese regions at the instructor's request. Images are aggregated to numeric series first; **models never take images as input**.

## Target structure

See the tree in README.md. Key conventions:

- `src/floodbench/` is the only place for reusable logic. Notebooks call it and plot; they do not define pipeline logic.
- Regions are config-driven: `configs/regions/<region>.yaml`, raw data in `data/raw/<region>/`, derived data in `data/{interim,processed}/<region>/`. Do not hard-code Mekong paths or constants in `src/`.
- All series share one long schema: `region, season, step, doy, target_km2` (plus optional covariates). Models and evaluation consume only this schema.
- `results/` is generated by code. `reports/` cites numbers from `results/` and never hard-codes them.
- Log decisions in `docs/decisions.md` and every tuning run in `docs/tuning_log.md`.

## Non-negotiable rules for fair comparison

1. Split by time, never shuffle. Rolling origin by year: train on seasons before Y, test on Y.
2. Every statistic used in preprocessing (climatology, scaler, mean, anomaly baseline) is computed from the training fold only, inside each fold.
3. Always report baselines in the same table as the models: persistence, climatology, 5-year climatology, seasonal naive.
4. Same features for statistical and ML models unless a model is explicitly documented as using more.
5. Equal tuning budget per model, logged in `docs/tuning_log.md`. Never tune on the test fold.
6. Compare models with season-level tests (the unit is the season, not the 27 steps inside it). Step-level errors are strongly autocorrelated (AR(1) of anomaly is about 0.89), so a pooled Diebold–Mariano test overstates significance.
7. "Failed to reject" is not "equivalent". Use confidence intervals and TOST for equivalence claims.
8. Do not claim causation (levees, dams). Say "consistent with".
9. Do not use Prophet by default.

## Data gotchas (Mekong set)

- Flood rasters cover about 380,000 km² including Cambodia. Clip to the Mekong Delta mask (about 39,900 km²) before computing anything.
- Grids differ by year: 232 m and 500 m. Convert to km², resample to a common grid by **mean or majority**, not nearest-neighbour.
- 485 files are `.tif` (GeoTIFF); 80 files (2018–2020) are `.tiff` but are raw ENVI, read via `.hdr`. One file has a space in its name (`Flood_2017_ 289.tif`).
- 565 of 567 expected maps exist. Missing: 2013 day 233 and 2019 day 257. Interpolate linearly and flag them.
- Each season is a separate 27-step segment (day 153 to 361, 8-day spacing). Do not concatenate seasons into one continuous series for SARIMA.
- The target is a derived product (decision tree on MODIS EVI/LSWI), not a direct observation. State this in any write-up.
